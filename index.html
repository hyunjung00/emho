Abstract

Improving embodied agents often focuses on optimizing the underlying model through training, while the surrounding agent harness that controls planning, context, and tool use is typically engineered. We ask whether this harness can instead improve itself directly from experience traces under sparse environmental feedback. We propose EMbodied Agent Harness Optimization (EMHO), a self-evolving framework that keeps the embodied model frozen and iteratively revises its harness by analyzing execution trajectories and prior harness history. EMHO optimizes beyond skills or recovery prompts, modifying how the agent monitors progress, uses vision tools, grounds observations, and responds to failures. To support multiple subtasks with a single harness, we introduce EMHO-Merge, which addresses trade-offs in jointly optimizing a single shared harness across subtasks by using episode-level gains and losses to guide evidence-supported refinement of when and how revised behaviors are applied. We evaluate EMHO on EmbodiedBench across navigation and manipulation tasks, and EMHO consistently improves task success for both Qwen 9B and 27B models. Qualitative analysis shows that EMHO goes beyond recovering from failures and unproductive actions to reshape how the embodied agent interprets and interacts with its environment.

EMHO-Merge

EMHO-Merge uses episode-level gains and losses to refine when revised behavior should activate in a shared harness. In the 27B three-subtask search setting, it improves average success over combined EMHO from 61.1% to 67.8% for navigation and from 34.7% to 39.8% for manipulation.

Qualitative Analysis

What changes when the model stays frozen but its harness evolves? We compare initial and evolved behavior on held-out trajectories, primarily with the 27B model, and group the changes into five types.

Recovery Edits

Recovery edits govern what happens after an action fails or the trajectory stops making progress. The key distinction is whether the environment reports a failure or the harness must recognize ineffective behavior itself.

Invalid-Action Recovery

Use explicit failure feedback to change the next attempt. A blocked or invalid action becomes a constraint on subsequent planning. In navigation, EMHO retains blocked directions and prompts the agent to reorient or take a short detour before approaching the target again. In manipulation, it carries execution errors, such as path-generation failures, into replanning so the agent can revise the target location or approach direction.

Valid-but-Ineffective Action Recovery

Recognize lack of progress even when actions are valid. Repeated rotations, reversals, or grasp attempts can execute successfully without completing the task. EMHO checks recent actions and observations for these patterns and requires a meaningful change in strategy. Navigation can break out of rotation loops; manipulation can revise the grasp point, approach height, or object estimate instead of reissuing the same plan.

In the manipulation analysis, identical replans decrease from approximately 21% to 18%, and repeated grasps at the same coordinates from approximately 30% to 26%.

Non-Recovery Edits

Non-recovery edits shape ongoing decisions without requiring a failure signal. They change how the agent tracks progress, selects useful visual evidence, and connects what it sees to its next action.

Progress Monitoring

Track what has changed and what remains to be done. In navigation, EMHO compares successive views, including the target's apparent position and size, to assess whether motion is bringing the agent closer. In manipulation, it tracks approach, grasp, lift, translate, and release. The current gripper and object state guide the next unfinished phase, helping the agent continue a partially completed task instead of restarting the sequence.

Tool Selection and Orchestration

Choose vision tools for the uncertainty that matters next. Depth estimation supports obstacle, proximity, and clearance reasoning; segmentation helps identify a target; and zoom reveals finer details in a relevant region. In the navigation example, the evolved harness uses depth after blocked moves to inform its next action. In manipulation, it requests depth proactively for height-sensitive interactions such as stacking and container placement.

After blocked navigation moves, depth-tool use rises from approximately 70% to nearly 100%, alongside an increase in valid subsequent actions from approximately 44% to 68%.

Perception and Visual Grounding

Connect the intended object to an action grounded in the current view. Navigation compares candidate targets using attributes from the instruction and uses the selected visual evidence to guide motion. Manipulation distinguishes object identity from executable grasp coordinates and re-evaluates both during planning. In the wiping example, the evolved harness distinguishes the sponge from the colored surface regions and selects the sponge's location.

In the spatial-relation analysis, incorrect object selection in initial plans decreases from 50% to 34%. This measures object choice during planning, rather than fine-grained grasp-coordinate accuracy.

These are behavioral measurements, not overall task success rates. See Section 5 and Appendix D of the paper for the full analyses.
